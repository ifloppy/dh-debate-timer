# dh-debate-timer

A debate timer designed for Debate club of Shanghai Donghai College. 

Proudly built with Svelte.js & licensed under GPL v3.

User manual: [简体中文](/docs/manual_zh.md)

## Developing

```sh
npm run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
```

## Building

```sh
npm run build
```
